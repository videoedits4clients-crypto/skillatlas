    Beginner guide

    Everything you need to go from “what's a skill?” to using one — in about three minutes.

    1

    What is a skill?

    A skill is a folder with a SKILL.md file: plain instructions (and sometimes scripts or templates) that teach an AI assistant how to do one job well — like filling PDF forms, building slide decks, or following your brand style.

    The assistant only loads a skill when it's relevant, so you can install many without slowing anything down.

    2

    How to pick one

    • Start with a category that matches your goal, not a tool name.
    • Prefer “Official” skills (made by Anthropic) when one exists.
    • Stars show how many people trust the collection it comes from.
    • Watch for 🔑 Needs key: that skill needs an account with an outside service, which may cost money.
    • Read the preview — a good skill explains clearly when it should be used.
    3

    How to install

    Claude apps (web/desktop): click Download .zip, then go to Settings → Capabilities → Skills and upload it.

    Claude Code: copy the one-line install command from the skill's page — it drops the folder into ~/.claude/skills/.

    Other agents: most tools that support the open Agent Skills format read the same folder — check your tool's docs for its skills directory.

    !

    Stay safe

    Skills can include scripts that run on your machine. Before installing a community skill, open its SKILL.md preview and glance at any scripts. If something looks off — or asks for secrets — skip it.

    SkillAtlas links to the original source; it doesn't review or host the code.

    Questions people ask

    How often is this updated?

    About every 2 hours. GitHub runs the job on a best-effort schedule, so it is sometimes later; the label at the top of the homepage shows the real time of the last update. A scheduled job scans GitHub for repositories that contain SKILL.md files, reads each skill's name and description, sorts it into a category, and republishes the site.

    Do skills cost money? What does “Needs key” mean?

    Skills themselves are free to download. Most only need your AI assistant (Claude or another agent). Some connect to an outside service such as OpenAI, ElevenLabs or Composio, and you'd need your own account or API key there. Those services may charge. Skills like this show a 🔑 Needs key badge naming the service, and Optional key means it works without one. Turn on 🔓 No API key needed above the results to hide them. This is detected automatically from each skill's instructions, so treat it as a strong hint, not a guarantee.

    What does the icon next to a name mean?

    It means the skill is trending: its collection is one of the fastest-growing on GitHub this week, counting both new stars and how fast it's growing for its size. Hover over the icon to see how many stars it gained. The list is recalculated with every update.

    What do 🚀 Rising and 💎 Gem mean?

    🚀 Rising marks skills from a collection that is less than four months old and gaining GitHub stars unusually fast for its age. These are often the ones people have just started sharing. 💎 Gem marks skills from small collections (under 1,500 stars) that are still being maintained. The site scans the most popular collections, the fastest-growing new ones, and a spread of small ones, so a skill doesn't need to be famous to be listed.

    What is a skill pack? What is a niche?

    A pack is a set of skills one author publishes together in a single GitHub repository, for example a marketing kit or a set of research tools. You can install one skill from it or download the whole pack. A pack marked 🔓 No API keys has no skills that need an outside account. A niche is a specific job, like video editing, SEO or resume writing. Niches are narrower than categories, and one skill can appear in several. Both are assigned automatically from each skill's name and description.

    Where do the skills come from?

    Anthropic's official repositories, well-known curated “awesome” lists, and public GitHub repositories tagged with topics like claude-skills or agent-skills. Repos need a minimum number of stars to be listed, which filters out most spam and experiments.

    Why do I see the same skill name twice?

    Different authors sometimes publish skills with the same name. Exact copies are merged into the most-starred source; genuinely different versions are kept so you can compare.

    A category looks wrong.

    Categories are assigned automatically from each skill's name and description, so a few will be off. The search box looks at everything, so searching is the fastest way to find something specific.

    My skill isn't listed. How do I add it?

    Publish it in a public GitHub repo with a SKILL.md (with name and description frontmatter) and add the claude-skills or agent-skills topic to the repo. It'll show up once it passes the star threshold.
